#definition

Given a [[Set]] $A$ and an [[Equivalence Relation]] $\sim$ on $A$, the **quotient** $A/\!\sim$ of $A$ under $\sim$ is the set of parts of the corresponding [[Partition]] (see [[Partitions Correspond to Equivalence Relations]]).

> Sources: 7 Sketches Definition 1.21; Kittenlab Lecture 9, 11.

There is a canonical [[Surjection]] $q : A \twoheadrightarrow A/\!\sim$ sending each element to its class. Categorically, $A/\!\sim$ is the [[Coequalizer]] of the two projections $R \rightrightarrows A$ from the relation $R \subseteq A \times A$: it is the universal way of "squishing" $\sim$-related elements together (Kittenlab Lecture 11: angles $\theta \sim \theta + 2\pi$ give $[0, 2\pi)$ or the circle $S^1$). [[Pushout|Pushouts]] in $\mathbf{Set}$ are quotients of disjoint unions.

```haskell
-- Haskell has no quotient types; represent A/∼ by a choice of representatives
import Data.List (nubBy)
quotient :: (a -> a -> Bool) -> [a] -> [a]
quotient eq = nubBy eq
-- the canonical surjection picks the first representative
classOf :: (a -> a -> Bool) -> [a] -> a -> a
classOf eq reps a = head [r | r <- reps, eq r a]
```
