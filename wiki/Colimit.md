The **colimit** of a [[Diagram]] $D : \mathcal{J} \to \mathcal{C}$, written $\mathrm{colim}\,D$, is the universal [[Cocone]]: the [[Initial Object]] in the category of cocones under $D$. Equivalently it is a [[Representable Functor|representing object]] for $\mathrm{Hom}_{\mathcal{C}^{\mathcal{J}}}(D, \Delta(-))$: $[\mathcal{J}, \mathcal{C}](D, \Delta_x) \cong \mathcal{C}(\mathrm{Colim}\,D, x)$ (Kittenlab Lecture 9, DaoFP §9.5). 7 Sketches' "compressed" definition: a cocone in $\mathcal{C}$ is a cone in $\mathcal{C}^{\mathrm{op}}$, and the colimit of $D$ is the limit of $D^{\mathrm{op}}$ (Definition 3.102). Kittenlab's slogan: **"colimits are gluing"** — take the disjoint union ($n$-ary [[Coproduct]]) of the objects, then glue parts together (by [[Equivalence Relation|equivalence relations]], computed with union-find).

> Sources: Kittenlab Lecture 9 ("Colimits"), 11, 15; DaoFP §9.5, §10.4, §10.7, §12.6 ("Initial Algebra as a Colimit"), §17.2 ("Colimits as coends"), §19.4; 7 Sketches §3.5.4, §6.2 (Chapter 6 unpacks colimits: initial objects, coproducts, pushouts, finite colimits, cospans), §3.4.4 ($\Sigma$-operations are built from colimits).

## Special cases

| shape | colimit |
|---|---|
| empty | [[Initial Object]] (in $\mathbf{Set}$, $\varnothing$) |
| $n$ objects, no arrows | $n$-ary [[Coproduct]] |
| [[Span]] $\bullet \leftarrow \bullet \to \bullet$ | [[Pushout]] |
| parallel pair $\bullet \rightrightarrows \bullet$ | [[Coequalizer]] (e.g. $G/H$ for a subgroup $H \leq G$ in $\mathbf{Ab}$, coequalizing the inclusion and $0$; angles $\mathbb{R}/2\pi\mathbb{Z}$) |
| a [[Preorder]] as $\mathcal{C}$ | [[Join]] $\bigvee$; joining systems ([[Generative Effect]]) |
| $\mathbf{Set}$, any finite diagram | disjoint union of the $D(v)$ modulo the equivalence relation generated by $d \sim D(a)(d)$ (7 Sketches Theorem 6.x, Kittenlab) |
| $! : \mathcal{C} \to \underline{1}$ | $\Sigma_!(I) = \mathrm{colim}\,I$: connected components / quotients ([[Data Migration Functor]]) |
| $\omega$-chain $0 \to F0 \to F^2 0 \to \cdots$ | the [[Initial Algebra]] of $F$ (DaoFP §12.6) |

## Properties

- Unique up to unique isomorphism. $\mathbf{Set}$ is **cocomplete**; [[C-Set|C-set]] categories and [[Category of Graphs|graphs]] have all colimits, pointwise (glue vertices and edges separately).
- $\mathrm{Colim} \dashv \Delta$ (DaoFP §10.4); left adjoints preserve colimits ([[Right Adjoints Preserve Limits|dual]]); the contravariant [[Hom Functor]] turns colimits into limits: $\mathcal{C}(\mathrm{Colim}\,D, x) \cong \mathrm{Lim}\,\mathcal{C}(D-, x)$. Colimits are [[Coend|coends]] and left [[Kan Extension|Kan extensions]]. Every presheaf is a colimit of representables.
- **Isomorphic diagrams have isomorphic colimits** (Kittenlab Lecture 15): $F \cong F'$ gives $\mathrm{Hom}(F, \Delta-) \cong \mathrm{Hom}(F', \Delta-)$, so the representing objects agree — "that's Yoneda, baby!" This makes composition of [[Cospan|cospans]] by pushout well defined on isomorphism classes.
- Colimits are where [[Generative Effect|generative effects]] live: an observation that fails to preserve colimits sees more in the whole than in the parts. Colimits of [[Hypergraph Category|network diagrams]] describe *connection* (7 Sketches Chapter 6: "colimits and connection").

````tabs
coproduct(FinSet(2), FinSet(3)) |> apex        # FinSet(5)

# colimits of graphs are computed the same way, pointwise

colimit(Span(id(G), id(G))) |> apex == G      # (up to iso) pushout along identities

-- colimits in Hask of finite diagrams: a disjoint union modulo generated equivalence
-- e.g. the pushout of f :: z -> x and g :: z -> y on finite carriers, via representatives:
pushoutSet :: (Eq x, Eq y) => [x] -> [y] -> [z] -> (z -> x) -> (z -> y) -> [[Either x y]]
pushoutSet xs ys zs f g = classes
  where pairs   = [ (Left (f z), Right (g z)) | z <- zs ]
        elems   = map Left xs ++ map Right ys
        related a b = a == b || (a, b) `elem` pairs || (b, a) `elem` pairs
        closure a = [ b | b <- elems, reach a b ]
        reach a b = a == b || any (\c -> related a c && reach' c b [a]) elems
        reach' c b seen = c == b || any (\d -> related c d && not (d `elem` seen) && reach' d b (c:seen)) elems
        classes = foldr (\e acc -> if any (e `elem`) acc then acc else closure e : acc) [] elems
```
````
