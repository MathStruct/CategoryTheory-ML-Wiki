**Exercise 1.67.** Show that if $(P, \leq_P)$ is a [[Discrete Preorder]], then every function $P \to Q$ is [[Monotone Map|monotone]], whatever the order on $Q$.

## Solution

If $p_1 \leq_P p_2$ then $p_1 = p_2$ (discreteness), so $f(p_1) = f(p_2)$, and hence $f(p_1) \leq_Q f(p_2)$ by reflexivity.
