**Exercise 4.7.** Show that $\Rightarrow$ (with $\mathsf{true} \Rightarrow \mathsf{false} = \mathsf{false}$ and $\mathsf{true}$ otherwise) satisfies $b \wedge c \leq d$ iff $b \leq (c \Rightarrow d)$.

## Solution

Same as [[7S Exercise 2.84]]: if $c = \mathsf{false}$ both sides always hold; if $c = \mathsf{true}$ both sides say $b \leq d$. See [[Bool (Monoidal Preorder)]].
